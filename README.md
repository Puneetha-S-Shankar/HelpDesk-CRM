# PropDesk (Next.js)

Helpdesk CRM front end. Next.js App Router, TypeScript, Tailwind v4.

    npm install
    npm run dev      # http://localhost:3000

- `components/App.tsx` shell, dashboard, queue, ticket pages
- `components/Enterprise.tsx` roles, licensing, users + skills, categories, SLA policies, escalation builder, skill routing
- All data is in-memory sample data for now. Next step is a FastAPI backend.
